# RNMaps

Projeto desenvolvido com React Native + Expo para estudar e experimentar mapas, localização e geolocalização em aplicações mobile.

## Tecnologias

* React Native
* Expo
* TypeScript
* Expo Location
* React Native Maps

## Funcionalidades

* Obter a localização atual
* Exibir mapas
* Adicionar marcadores
* Trabalhar com latitude e longitude
* Solicitar permissões de localização
* Interagir com o mapa

## Instalação

```bash
git clone https://github.com/marioestima/rnmaps.git
cd rnmaps
npm install
```

Inicie o projeto:

```bash
npx expo start
```

Depois, abra o projeto no Expo Go ou em um dispositivo/emulador compatível.

## Objetivo

O objetivo deste projeto é aprender na prática como trabalhar com mapas e localização no React Native, explorando o Expo Location e o React Native Maps.
